# PROMPT

## 添加新内容

### 大框合并

现在，比赛框将支持合并为一个大框，即同一个大框内所有比赛共用同一个接入口，新接入口要求接入数量即为单一比赛框数量的2倍或赛果框数量的一倍。但是出口保持不变，不产生合并。同时，由于接入口混淆，单一比赛框合并的大框下的比赛必须在接入口接满才能安排比赛，比赛排法则具有算法，该算法选项同样有提供的预设算法与玩家自导入的代码，目前自导入代码部分仅留占位，具体细节待回到CSEMTV Godot项目再结合其他信息实现。

提供的算法有（假设大框内有3场比赛，6支队伍的本阶段起始层排位为1，2，3，4，5，6）：按本阶段排序直接从上至下填入（1-2，3-4，5-6），从上到下交错（1-4，2-5，3-6），首尾结合（1-6，2-5，3-4）。

同时，大框还需要满足大框内比赛框（由上而下）紧密排列，且大框顶部显示有居中的可编辑的额外标签，标签算作大框的性质。

当大框由赛果框合并而来时，则还需要额外满足：大框内所有战队的排名相同，无论是推送至下一阶段还是淘汰，且大框提供的排名显示须为以$\sim$表示的区间形式，玩家输入区间的左端，大框自动根据框内战队数目计算右端，如当大框内有 3 个赛果框且输入的左端为17时，则排名显示为$17 \sim 19$。引入此机制之后，则排名不允许重复，即若玩家需要同排名，则必须设置大框。程序需要额外校验排名是否不重且全覆盖，全覆盖指每一阶段的X支推送下阶段队伍排名的并为$1 \sim X$，且全阶段的Y支战队的排名的并为$1 \sim Y$。

大框的样式为初始时2格高度，将比赛框拖入大框时自动吸附（若大框内不为空且正在拖动的框类型（单一比赛框/下阶段推送赛果层/淘汰赛果层）与大框内不匹配时，不自动吸附，且起始层不参与自动吸附），且有比赛框时样式为框上1格，框下1格。大框用于网格吸附的部分与赛果框等宽（即10格），但是视觉上需具有左右各约1/5格宽的半椭圆边框。新的通道接入口的位置为顶部格子的最左端，当比赛框和赛果框在大框内部时。标签位置则为大框的顶端，且需要加粗。

大框功能的入口在新建单一比赛框和赛果框右侧，提示为“新建大框”。

### 伪大框

仅在视觉效果上与大框相同的标签与辅助限位功能。伪大框不改变接入口逻辑，也不影响框内小框的比赛设置或排名设置，仅帮助玩家将单一比赛框或赛果框紧密排列并赋予可编辑的额外标签。

伪大框功能的入口在新建大框右侧，提示为“新建大框（仅标签）”。

### 右键复选框

右键滑动选择一个区域，将区域内所有元素（不包括起始层和由种子层连接至起始层的通道）全部加入复选。当元素类型全部相同且不为大框或伪大框时，则有“设为大框”和“设为大框（仅标签）”功能。当元素类型均为赛果框（此时不区分下阶段推送和淘汰），则有“全部设为下阶段推送”和“全部设为淘汰”功能。无论如何，都有“全部删除”功能，且支持快捷键Del/Backspace。无论如何，都有“复制”和“剪切”功能，且支持快捷键Ctrl+C/Ctrl+X。无论如何，均可以批量拖动框。

### 复制，剪切与粘贴

复制/剪切时，将信息写入程序自设的缓存区画布而非用户的剪切板，即当复制/剪切的对象不是纯文本时，劫持Ctrl+C/Ctrl+X快捷键。复制的内容包括：比赛框、赛果框、大框、框的相对位置、形式上管道的连接方式。注意，内容不包括不影响框类型的框内信息（如排名设置、大框排序算法、大框标签内容等）。

劫持Ctrl+V快捷键，判断：当且仅当鼠标悬停于画布时，则将缓存区内容粘贴至悬停位置，鼠标位置为画布中心点。缓存区画布自动规划为框的最小覆盖矩形。若当前在输入文本，则恢复为正常的从用户剪切板粘贴。
